# pH meter reference

Viewed the main product photograph on the [Hanna HI6221 page](https://hannainst.com/advanced-ph-and-orp-meter-HI6221-01.html?search_query=6221&searchid=828356). It informed the shallow angled touchscreen base, paired articulated links, electrode clamp, green electrode head, clear glass electrode and separate metallic temperature probe. The listed base dimensions are 205 × 160 × 77 mm.

Original unbranded geometry with approximate arm lengths and accessory dimensions. The demo raises/lowers both probes together, blocks beaker removal while lowered, and shows a fixed virtual reading only when powered and lowered. It does not simulate electrochemistry or teach a calibration sequence. The beaker is a neutral demonstration prop. Source photography is not bundled.
