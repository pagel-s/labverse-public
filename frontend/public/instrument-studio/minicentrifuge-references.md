# Mini centrifuge reference

Inspected the open/closed instrument and rotor photos on page 4 of the [Eppendorf microcentrifuge brochure](https://www.eppendorf.com/product-media/doc/en/335096/Centrifugation_Brochure_Microcentrifuges_MiniSpin_MiniSpin-plus_Centrifuge_5418-R_5420_5425_5425-R-5427-R_5430_5430-R_Your-Daily-Companion.pdf). The MiniSpin family informed the rounded shell, rear hinge, inset controls and twelve-position rotor. The page 14 table supplies a 225 × 230 × 130 mm closed envelope.

Original code geometry; no manufacturer logo or source photography is included. Curvature, internal clearances, keypad and underside are visual approximations. The demo uses neutral tube props, a removable rotor cover, a lid lock and shortened motion. It does not simulate separation or provide operating settings. Loading a visual opposite pair is not a real balance check.

Validation: 26 state assertions passed. Browser checked prop placement, rotor cover, lid closure, lock refusal during motion, completion and release. Both open and closed geometry reviewed.
