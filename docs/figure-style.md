# Figure Style

The recommended manuscript figures are generated by
`scripts/plot_paper_journal_figures.py`.

The style is intentionally conservative and benchmark-oriented:

- Use scenario-grouped bar plots for headline success rates.
- Encode models with a restrained sequential color gradient and keep that mapping fixed.
- Facet planner/interface conditions when showing per-scenario outcomes.
- Avoid large in-mark value labels; use a final mean group for compact summary statistics.
- Use a warm off-white paper background, muted gridlines, and dark neutral text.
- Keep exact values, counts, and secondary statistics in CSV/table sources.
- Use matrices only for direct grid comparisons, such as initial-state sensitivity.
- Put detail-heavy diagnostics in SI, not the main figure stack.
- Avoid decorative gradients, heavy boxes, dashboard-style cards, and saturated model palettes.

Main manuscript figures:

```text
journal_main_benchmark
journal_failure_taxonomy
journal_sensitivity
```

Supplementary figures:

```text
journal_si_diagnostics
```

The older `styled_*` and `camera_ready_*` outputs are retained for comparison,
but the `journal_*` family should be treated as the clean publication baseline.
